# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take security seriously, especially regarding LLM prompt injections, data leakage, and API security.

If you discover a security vulnerability:
1. **Do not open a public issue.**
2. Send an email to `sanmitpatil07@gmail.com` with details of the vulnerability.
3. Include steps to reproduce and proof-of-concept payload where applicable.

You will receive a response within 48 hours.
