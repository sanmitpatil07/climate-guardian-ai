# Contributing Guidelines

Thank you for your interest in contributing to this project!

## Development Workflow

1. **Fork the Repository**: Create your feature branch (`git checkout -b feature/amazing-feature`).
2. **Commit Changes**: Use clean commit messages following Conventional Commits (`feat: add satellite vision tool`).
3. **Run Tests**: Ensure all unit tests pass (`pytest`).
4. **Push Branch**: `git push origin feature/amazing-feature`.
5. **Open Pull Request**: Detail the changes, design rationale, and test verification.

## Code Style
- Follow PEP 8 guidelines for Python code.
- Type hints are required for all function signatures.
- Add docstrings to public classes and methods.
